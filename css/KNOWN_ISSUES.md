# 알려진 문제 · 남은 일 (v593)

## 사용자가 직접 해야 하는 것
- **실기기 점검**: 아이폰 Safari(홈 화면 앱)와 안드로이드 Chrome에서 `docs/실기기점검표.md`를 따라 확인. 이 환경에서는 샌드박스(390~430px 화면)에서만 확인했습니다.
- **라이브러리 내려받기**: 인터넷 되는 컴퓨터에서 `node tools/fetch-libs.js` 실행 후 `lib/` 폴더를 함께 올리면 오프라인에서도 PDF·엑셀·이미지 저장·글꼴 사용. 실행하지 않아도 앱은 동작(처음 한 번은 인터넷 필요).
- **GitHub 커밋 · CHANGELOG**: 이 환경에서는 Git을 쓸 수 없습니다.

## 알려진 한계
- 글자 인식(OCR) 도구는 첫 사용 시 인터넷에서 받습니다(용량이 커서 `lib/`에 포함하지 않음).
- 처음 방문 시 필수 다운로드가 약 1.4MB(압축 기준). JS 안에 박힌 이미지 약 700KB(견적서·인쇄용)가 남아 있어 시작 시간 추가 개선 여지가 있습니다.
- 저장소가 둘로 나뉘어 있음(localStorage·IndexedDB). 통합은 이전 위험이 커서 하지 않기로 결정. 대신 백업이 모든 항목을 포함하고 저장 실패 시 알림이 뜹니다. TDS 원본 PDF·사양 사진은 용량 때문에 백업에서 제외됩니다.
- 입력칸 글자 14px: 아이폰에서 입력 시 화면이 확대될 수 있습니다(16px 이상이면 방지, 일위대가표 기준과 맞춰 14px 유지).
- 버튼·글자 크기 표준은 스크립트가 클래스를 붙여 맞춥니다. 화면 코드에 직접 클래스를 넣는 정리는 하지 않았습니다.
- 덧씌우기 스타일(`!important` 약 1만 회)이 남아 있습니다. 새 화면을 만들 때 이전 보정과 충돌할 수 있습니다.
- 일위대가표 계산 화면은 표준화 대상에서 제외(기준 화면).

## 결정 보류 · 하지 않은 것
- 일위대가표→LCC 자동 반영(v425에서 삭제한 기능)은 되살리지 않음. 도장 시스템의 "LCC 사양으로 보내기"로 대체.
- 화면 배치가 바뀌는 보완(홈 카드 축소·"다음 할 일" 한 줄, 하단 버튼줄 축소, 공동주택 빈 상태 버튼, 단가 기준일 입력)은 보류. 허락 시 진행.
- "추천 희석" 표현: 견적서 코드에서 찾지 못함. 어느 화면인지 캡처 필요.
- 최종 배포 형태(홈 화면 앱 → 스토어 앱·클라우드)는 향후 결정.

## 결함·LCC 개선(제안서 기준) 진행 상태
- A0~A2 완료(기반): DGE 기준 단일화, 진단 기록 확장, 이력 보존. 화면·계산 결과는 바뀌지 않음.
- 신뢰 등급 A/B/C 경계(0.85/0.6), 안전 관련(균열·박리 3등급 이상) 기준은 잠정값 — 사내 기준 확정 시 js/072-dge.js의 TH·safety만 수정.
- 시공품질형(6)·외관형(2) 결함은 현재 LCC 계산에 반영하지 않음(보고용). 제안서의 "검수 완료 신규 8종 반영" 해석은 기준 확정 후 A3에서 결정.
- A3 엔진 완료(js/073-dgs.js): 화면 연결 전. 국부 보수 면적 배수·상하한, 지연 연수, 불확실성 폭은 모두 잠정값(DGS.P, 자산별 a.dgsP).
- A4 완료: 보고서 4단계 아래 시나리오 카드(진단이 적용된 자산에만 표시). 카드 수치 기준은 잠정값.
- 남은 것: 보고서 외 화면(LCC 분석 단계)에서의 요약 표시, A5(학습 자료 백업·골든세트), 결함별 수명 보정 기준 확정, 실기기 확인. (이전 메모: A4(신뢰도·범위 표시 — 화면 변경 허락 필요), A5(학습 자료 백업·골든세트).
- A5 완료: 백업에 학습 자료 포함(사진 30MB 상한 — 초과분은 제외되며 안내 표시). 골든세트 평가(모델 점수 산출)는 PC 학습 도구에서 골든 내보내기 파일로 수행 — 앱 안 자동 평가는 미구현.
