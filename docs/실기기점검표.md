# 실기기 점검표 (아이폰 Safari 홈 화면 앱 · 안드로이드 Chrome)

점검 방법: 아래를 순서대로 해 보고 막히는 곳의 화면 캡처와 기종을 보내주세요. (✅ 정상 / ❌ 문제)

## 0. 설치
- [ ] 아이폰: Safari로 열기 → 공유 → 홈 화면에 추가 / 안드로이드: Chrome → 앱 설치
- [ ] 홈 화면 아이콘으로 열면 주소창 없이 전체 화면으로 열림
- [ ] 시작 화면이 3초 안에 보이고 "확인했습니다" 후 홈으로 이동
- [ ] 노치·하단 홈바에 하단 메뉴가 가려지지 않음

## 1. 핵심 흐름 (끝까지)
- [ ] 일위대가표: 면적 입력 → 제품 선택 → DFT·SVR 입력 → 결과 표시
- [ ] 세부 내역 창이 열리고 하단 메뉴가 보임·눌림
- [ ] 견적서 생성 → 화면 확인 → (PDF/이미지) 저장 또는 공유
- [ ] 전체 초기화 → 하단 "되돌리기" 막대로 복구
- [ ] LCC: 자산 선택 → 사양 → 비용 결과
- [ ] 공동주택 견적: 단지 검색 → 견적 작성

## 2. 입력·화면
- [ ] 입력칸을 누를 때 화면이 확대되지 않는지(확대되면 알려주세요)
- [ ] 키보드가 올라와도 입력칸·버튼이 가려지지 않음
- [ ] 하단 메뉴 5개 모두 이동 가능, 뒤로가기 동작이 자연스러움
- [ ] 글자·버튼 크기가 읽기·누르기 편한지(너무 작은 곳 캡처)

## 3. 저장·백업
- [ ] 앱을 완전히 닫았다 열어도 입력 값 유지
- [ ] 설정 → 백업 저장 → 파일이 저장·공유됨
- [ ] 같은 백업 파일을 복원(병합) → 값이 같음
- [ ] 비행기 모드(오프라인)에서 앱이 열리고 계산이 됨

## 4. 파일·사진
- [ ] 제품 TDS PDF 첨부·열기
- [ ] 현장진단 사진 촬영/선택 → 진단 결과 표시
- [ ] 공유 버튼으로 카카오톡·메일 전송

## 5. 속도 (체감)
- [ ] 처음 설치 후 첫 실행 시간 / 두 번째 실행 시간 (초 단위로 알려주세요)
